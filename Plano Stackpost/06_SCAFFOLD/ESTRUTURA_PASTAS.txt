## Como inicializar

```powershell
# 1. Criar estrutura base
mkdir stackpost
cd stackpost
pnpm init
pnpm add -D turbo typescript @types/node

# 2. Criar workspaces
pnpm-workspace.yaml:
  packages:
    - "apps/*"
    - "packages/*"

# 3. Backend
mkdir -p apps/backend
cd apps/backend
pnpm dlx @nestjs/cli new . --package-manager pnpm --strict

# 4. Dashboard
cd ../..
mkdir -p apps/dashboard
cd apps/dashboard
pnpm dlx create-next-app@latest . --typescript --tailwind --app --use-pnpm

# 5. Shared
cd ../..
mkdir -p packages/shared/src
cd packages/shared
pnpm init
pnpm add zod

# 6. Docker
# Copiar docker-compose.yml e .env.example de 06_SCAFFOLD/
cp "../Plano Stackpost/06_SCAFFOLD/docker-compose.yml" .
cp "../Plano Stackpost/06_SCAFFOLD/.env.example" .env
# Editar .env com suas credenciais

# 7. Subir
docker-compose up -d
```
